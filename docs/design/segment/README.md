# Segment design references

Visual references captured from the Segment page in the Figma file [Finalink / Payable Master Data](https://www.figma.com/design/ZxTH3qP7GXJTTmiuTBz4Cq/Finalink---Payable-Master-Data).

These are cropped PNG captures from the authenticated Figma viewer, not native Figma exports. The connected account has view/comment access only; Figma's native screenshot/export connector refused the file for lack of edit access. Captures were framed to the 1440×960 design canvas and may retain small canvas-selection/layout overlays. The source frames remain the authority for precise measurements and vector assets.

## PRD alignment

PRD section 9.1.2.5 is authoritative for behavior: Segment ID is required and unique, and Status is an Active/Inactive selection. The captured Add Form omits the ID field and depicts Status as a toggle. The implementation follows the PRD; treat these two controls as a recorded visual discrepancy rather than changing the requirements implicitly.
